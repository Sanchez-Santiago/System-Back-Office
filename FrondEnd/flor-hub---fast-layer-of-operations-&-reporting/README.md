## 🎯 Descripción

**Flor Hub** es la central operativa definitiva para la gestión de ventas, logística y analítica en tiempo real. Diseñada bajo una estética premium de alto impacto, combina la robustez de un sistema de back-office con la agilidad de un asistente de inteligencia artificial.

## 🤖 FLOR AI: Inteligencia Operativa
La joya de la corona. Un motor de consulta inteligente que permite:
- **Análisis Predictivo**: Consulta tendencias de ventas mediante lenguaje natural.
- **Smart Prompts**: Acceso instantáneo a reportes clave (Ventas del día, conversión por canal, etc.).
- **Interfaz Glassmorphism**: Una experiencia de usuario envolvente y moderna.

## ✨ Características Estelares

### 💎 Diseño Ultra-Moderno
- **Glassmorphism & Micro-interacciones**: Interfaz fluida con efectos de cristal y desenfoque.
- **Modo Oscuro/Claro Optimizado**: Contrastes perfectos para largas jornadas de trabajo.
- **Bento Grid Layout**: Organización inteligente de la información para una lectura rápida.

### 📊 Gestión Avanzada
- **Timeline de Ventas**: Visualización del progreso de cada operación en tiempo real.
- **Intelligence Hub**: Dashboards interactivos con Recharts y métricas de conversión.
- **Filtros Inteligentes**: Segmentación por país, supervisor, asesor y más.

## 🛠️ Stack Tecnológico

| Tecnología | Rol |
|-----------|-----|
| **React 18** | Núcleo de la interfaz |
| **TypeScript 5** | Seguridad y escalabilidad |
| **TanStack Query** | Gestión de estado asíncrono y caché |
| **Tailwind CSS** | Estilizado moderno y responsive |
| **Recharts** | Visualización de datos compleja |
| **Zod** | Esquemas de validación de datos |

## 📁 Arquitectura del Proyecto

```
src/
├── components/
│   ├── analytics/       # Inteligencia y Gráficos
│   ├── layout/          # Estructura y Navegación (Header, AI Chat)
│   ├── sale/            # Gestión de Ventas y Timeline
│   └── modals/          # Flujos de trabajo y Formularios
├── services/            # Lógica de comunicación con el Servidor
├── hooks/               # Motores de lógica reutilizables (Custom Hooks)
├── contexts/            # Proveedores de estado global
└── pages/               # Vistas maestras de la aplicación
```

## 🚀 Inicio Rápido

1. **Instalación**: `npm install`
2. **Entorno**: Configura tu `.env` con la URL de la API.
3. **Despegue**: `npm run dev`
